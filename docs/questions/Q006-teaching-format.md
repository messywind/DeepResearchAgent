# Q006｜学习讲解方式调整

> 创建日期：2026-09-04  
> 状态：verified  
> 关联专题：[`learning/00-learning-plan.md`](../learning/00-learning-plan.md)

## 用户反馈

之前的 Supervisor 讲解过于抽象、文字过多、排版不易阅读；代码只截取孤立行，没有交代上下文，因此难以理解。

## 调整后的讲解协议

- 先讲全局位置，再讲局部代码。
- 代码按连续上下文展示，避免只解释孤立语句。
- 一次只推进一个小闭环。
- 明确输入、处理、输出和状态变化。
- 用短段落和小图代替大段概念罗列。
- 先建立理解，再做小检查，最后才进入面试表达。
