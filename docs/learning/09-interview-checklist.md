# 09｜面试自测题

## 第一阶段自测

1. 为什么需要 Supervisor，而不是让一个 Agent 直接搜索并写报告？
2. 从 `run.ipynb` 发起请求后，顶层主图依次经过哪些节点？哪个节点真正负责网络搜索？
3. `research_brief`、`draft_report`、`notes`、`final_report` 分别处在流程的什么位置？
4. 如果搜索后报告内容明显不完整，你会优先检查哪三个文件？为什么？
5. 目前这个仓库能否直接作为 HTTP API 服务启动？请指出证据。

## 回答标准

每道题至少要能说清楚：

- 结论：用一句话回答。
- 证据：指出代码文件、节点或状态字段。
- 权衡：说明当前设计解决了什么问题，又牺牲了什么。
- 改进：如果生产化或规模扩大，你会怎么改。

## 复盘方式

回答不完整时，创建一篇 `Qxxx-主题.md` 问题记录，把自己的初始答案和纠正过程保存下来；不要只修改本页题目。
